# Private Traveller library

Admin entry: `/admin/library/traveller`.

Folders: Beginners, Elementary, Pre-Intermediate, Intermediate B1, Intermediate B1+, Intermediate B2, Advanced/C1, Teacher Resources.

All 49 supplied resource entries (48 links and one missing teacher-book link) are saved by level. They have not been downloaded or verified. The duplicate URL for C1 tests and teacher book is retained and labelled.

Actual uploads are stored locally under `apps/web/private/library/traveller/<level>/` using random identifiers, with original names kept as metadata. The existing original Beginners PDF can also be downloaded privately by an administrator. Students and teachers without admin rights cannot access this library. Existing enrolled-student course access remains unchanged.

Upload limit: 50 MB per file. Supported: PDF, MP3, WAV, M4A, OGG, FLAC, ZIP, RAR, 7z. File signatures are checked. Archives are never extracted or executed. This is local filesystem storage; preserve the private directory when backing up or deploying. No new database migration is needed.
